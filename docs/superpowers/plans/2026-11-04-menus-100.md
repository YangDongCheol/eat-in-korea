> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 메뉴를 123개에서 223개로 늘린다. 한식 국·탕·조림, 밥·구이, 면·분식·중식, 세계 음식과 가벼운 메뉴를 고르게 100개 더한다. 디저트는 3단계에서 따로 다루므로 넣지 않는다.

**Architecture:** 코드 변경 없음. `menus.js`에 메뉴 객체를 더하고, 메뉴 개수에 묶인 테스트 기준을 올리고, 서비스워커 캐시 버전을 올린다. 4개 작업이 각각 25개씩 더한다.

**Tech Stack:** 바닐라 JS 데이터 파일, `node run-tests.js`(현재 PASS 82/82).

**Spec:** `docs/superpowers/specs/2026-11-03-modes-design.md`(메뉴 필드 `ways`·`light`), `2026-11-03-eat-in-korea-design.md`(태그와 안전 문구 원칙). 이전 계획 `2026-11-04-menus-stage2.md`와 같은 규칙을 쓴다.

## Global Constraints

- 메뉴 객체 모양은 기존과 정확히 같다: `{ id, ko, emoji, rom, name: { en, zh }, desc: { en, zh, ko }, spice: 0|1|2|3, feel: "hearty"|"light", contains: string[], ways: string[], light: boolean }`. `id`는 영문 소문자 kebab-case로 유일하고 `ko`도 유일하다. 기존 123개는 한 글자도 바꾸지 않는다(오탈자도 건드리지 않고 보고만 한다). 아래 목록의 `id`는 제안이며, 충돌하면 바꾸되 유일해야 한다.
- `contains`는 `pork`, `meat`, `seafood`, `nuts`만 쓰고 **보수적으로** 단다: 국물·소스·육수·양념까지 보통 들어가는 재료를 모두 단다(돼지고기가 들어가면 `pork`와 `meat` 둘 다; 멸치·새우젓·생선소스·조개·가쓰오부시 육수가 흔하면 `seafood`; 땅콩·호두·잣·깨 소스·땅콩 소스 등은 기존 데이터의 관례를 따라 `nuts`). **확신이 없으면 태그를 더 단다. 테스트 기준을 맞추려고 태그를 빼는 것은 금지**(필요하면 메뉴를 하나 더 보태거나, 부족분을 그대로 보고한다).
- `desc`는 세 언어 모두 한두 문장의 쉬운 설명이다. `desc.ko`는 한글이 있어야 하고 `desc.zh`는 중국어 글자가 있어야 한다. 건강·다이어트·칼로리·소화 주장 금지(**금지어**는 `tests.js`의 `FORBIDDEN` 상수 하나만 쓴다). 설명에 견과류가 나오면 `nuts`, 돼지고기·햄·베이컨·소시지·스팸·만두가 나오면 `pork`를 단다(기존 테스트가 검사한다). 흔한 알레르기 재료(돼지고기, 해산물, 견과류)는 설명에서 숨기지 않는다.
- `ways`는 `"dine"`을 항상 포함하고 `["dine","delivery","home"]`의 부분집합이며 중복이 없다: 배달이 흔한 메뉴만 `delivery`, 집에서 흔히 해먹는 메뉴만 `home`. `light: true`는 맑은 국물, 두부·나물·채소·곡물 중심, 기름기와 양이 적은 편으로 알려진 메뉴에만, 확신이 없으면 `false`. `feel`은 대체로 `light`이면 `"light"`.
- 줄바꿈은 LF(`file <이름>`이 CRLF를 말하면 안 된다). 커밋 메시지 끝에 Co-Authored-By 줄. 브랜치 `feat/menus-stage2b`, GitHub에 올리지 않는다. 새 메뉴마다 `emoji`는 이모지 한 개, `rom`은 로마자(외래어는 일반 표기), 영어 이름은 한국에서 쓰이는 일반 표기.
- 아래 목록에서 이름이 기존 메뉴와 같은 요리면 추가하지 않고 보고한다(기존 이름과 의미가 겹치는지 먼저 대조한다).

## Review Focus

1. **태그 누락(안전)**: 탕·전골·조림의 해산물/멸치 육수·돼지고기, 외국 음식의 소스·토핑(베이컨, 피시소스, 땅콩, 새우, 가쓰오부시), 튀김·분식의 속(돼지고기·해물), 꼬치·구이 양념 → 항목별 확인.
2. **설명에 건강 주장** → 기존 `FORBIDDEN` 검사 + 리뷰어 확인.
3. **이름·의미 중복**: 목록 안과 기존 123개와의 중복(곰탕≈설렁탕 등은 다른 요리로 인정, 같은 요리는 제외).
4. **다이어트·채식 후보가 늘었는지**: 마지막 작업에서 방식×제한 조합별 개수를 출력해 보고(이전 값 대비).
5. **서비스워커가 옛 `menus.js`를 보여줌**: `eik-v8`로 올리지 않으면 폰이 옛 메뉴를 쓴다 → Task 4의 sw 테스트.
